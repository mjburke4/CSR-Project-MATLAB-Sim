The issued K kit is authentic and all 53 public component checks passed. The receiver-timer fix clears the previous stop: node 3 PHY draw 75 at 45.662638077 seconds consumes the native uniform with 51 payload bits. The returned run nevertheless has an earlier timing/order divergence than its final semantic stop.

- All 355 manifest files and 137 resolved MATLAB files match the issued kit. Source/candidate transform metadata matches. Accepted natural A was reused, with byte-identical traces and the exact prefix/configuration/runtime gates; it was not rerun.
- All 1,450 requested random values were consumed with matching guarded contexts: 286 MAC, 658 SYNC and 506 PHY. There are 244 TX context checks: 243 pass, followed by one rejected TX that was not registered or physically emitted.
- Only the first **1,281 merged events** match unconditional native order and rounded-nanosecond times: **1,097 consumed draws and 184 transmitted frames**. The last is node 8 SYNC draw 2 at **62.829015346 seconds**, native event 28475.
- Native next requests node 4 MAC draw 25 at **62.870833632**. MATLAB requests it at **62.881**, after node 8 PHY draws 3 and 4. Three positions in the merged sequence differ. Overall, 341 request times differ (one by +10.166368 ms and 340 by +13 ms); 58 TX times differ by +13 ms. There are also 121 requests with differing diagnostic interval/component endpoints. Time diagnostics were retained, not imposed as input or used as stopping guards.
- The prior 82-byte/4-child, 215-byte/7-child, 63-byte REQUEST and 109-byte DISCOVER boundaries still pass. All 12 eligible DISCOVER identity annotations were independently checked against actual frames and native security/address fields; nine contain differing outer identifiers. This exception does not cover SNMP or destination fields.

At **71.942 seconds**, node 5 TX 68 has three children and 166 total bytes in both engines. The sole semantic differences are the final SNMP_START child's destination: MATLAB outer HOP **4**, payload final destination **2**; native outer HOP **1**, payload final destination **1**. Native packet and payload hex independently decode to 1; the MATLAB raw frame independently contains 4 and 2. Thus this is a real generated management-message difference, not a comparator identity issue. Addressing is behavioral: the existing SNMP receive path discards commands whose embedded final destination is another node, rather than relaying them. The guard correctly stops before transmitting this child.

The source separately explains why requester state can differ. Native `ReceiveSnmpFromHop` retains an active duplicate requester for DONE, but calls `MarkDiscoveryNotNeeded(source)` only in its IDLE/new-session branch. The issued MATLAB `ControlWireNwk.receiveControl` appends the source to `ScanRequested` after that branch as well. An active duplicate can consequently be skipped as a later outbound discovery target. This is distinct from the earlier reliable KEY_UPDATE admission timing boundary; the audit does not attribute both differences to one cause.

The eight new timer checks actually passed, including all 1,542 allocator geometries, 1,352 acquisition deadlines, 811 TX targets, public receiver acquisition, fallback modes and the PHY-first/MAC-second completion pair. The 28 ns rejected-return path remains a source/arithmetic check, with no native captured execution. NoPath remains absent from the native network fixture. These component results do not establish full-network or 6,000-second parity, and the 15% target is not yet measured by this short continuation.
