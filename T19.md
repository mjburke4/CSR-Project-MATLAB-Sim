# Tranche 19: queued retry timing under full campus traffic

Copy your repaired, accepted T18 installation to a new short folder such as
`C:\csr19`. Extract every file in `t19up.zip` over that copied installation,
accepting replacements. The older public T6–14 checkpoint is not a sufficient
base for this update.

Start MATLAB in that copied root and run:

```matlab
clear functions
report = run_tranche19_validation;
```

The run executes all **700 portable tests**, including 30 new policy and
runner tests, followed by two complete 6,000-second campus cases:

| Case | DATA retry policy | Purpose |
| --- | --- | --- |
| `a128` | `actual-tx` | Confirm the existing default reproduces accepted T17 |
| `p128` | `native-provisional` | Measure queued-retry expiration and subsequent capacity/admission effects |

Both use seed 128 and preserve the full seven-node/six-flow campus history,
real PHY, autonomous routing, original traffic and continuous timing. The
experimental option does not become the default. CONTROL retry confirmation
retains its existing behavior. No PHY/ECC change is included.

Allow roughly **2–2½ hours for the pair**, plus tests and exports. This is an
estimate from your previous campus run; the experimental policy may take a
different amount of time. Each case prints its start and completion; there are
no additional simulation callbacks for progress reporting.

Upload the resulting **`results/t19/t19.zip`** for review. The checker will
compare totals and individual flows using a descriptive ±5% band, report
finite-stop drops/pending work, and verify default-policy regression. This
single-seed experiment does not establish statistical equivalence.

## Separate stages and completed-result reuse

The default output folder is fixed at `results/t19`. You can run stages
separately using that same folder:

```matlab
report = run_tranche19_validation([],struct('Phase','tests'));
report = run_tranche19_validation([],struct('Phase','a128'));
report = run_tranche19_validation([],struct('Phase','p128'));
report = run_tranche19_validation([],struct('Phase','finalize'));
```

Completed stages are reused only after their candidate, source, references,
MATLAB runtime and output hashes verify. Re-running the default command after
completed stages reuses them. It does not resume a partly executed simulation.
Preserve any failed/partial return for review; do not edit a candidate, receipt
or evidence file to force a check to pass. See `docs/tranche-19-runner.md` for
recovering completed stages after an interruption.
