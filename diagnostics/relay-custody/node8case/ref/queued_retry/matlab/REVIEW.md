# Queued DATA retry policy review

N stops at 324.753 seconds on node 5 TX 130: its 217-byte DATA child is HOP sequence 36 / source-5 attempt 250; native transmits sequence 29 / attempt 11. Rate, power, preamble, destination, bytes and reservation match. The accepted prefix contains 4,202 matched random requests and 769 verified physical transmissions. This is a queued-owner timing difference, not another signature label issue.

The earlier divergence is visible in the queue history. Sequence 29 first transmits at 313.82, then enters MAC as retry 1 at 315.820000027778. A shared resend scan fires at 318.498000027778 from a different actual transmission. The selected MATLAB `actual-tx` policy has set the queued retry unconfirmed, so the scan does not advance it. Native retains initial-transmission confirmation and enqueues retry 2 at 318.498000028, while its first retry is still waiting. Both transmit the first retry at 320.879. MATLAB enqueues the second retry only at 322.879000027778, after new sequence 36 was admitted at 322.260111113778. Native's older queued copy therefore wins the later FIFO opportunity. No priority rule needs changing.

The existing, unchanged HOP implementation already provides `Hop.DataQueuedRetryPolicy='native-provisional'` for this behavior. It retains confirmation and a provisional enqueue timestamp for DATA retries, installs no timer merely on retry enqueue, and lets later actual-TX-driven list scans retry or expire those owners. Actual TX replaces the provisional timestamp. The bundle also includes the source's unmatched-DATA sent fallback, based on the latest installed timer handle. CONTROL queued retries continue to wait for actual TX. Existing ACK/DACK, expiration, cancellation and overload callbacks are preserved.

This option originated as an explicit T19 experiment. Its documentation deliberately preserved the `actual-tx` default; historical seed-128 evidence did not justify promotion and showed increased terminal loss. That is a limit on adopting a default, not a reason to conceal a now-localized mismatch. O selects the existing option only in its common-input case. The global/A configuration and 74 retained component checks keep their original settings. The actual O configuration is exported beside its traces, and the runner restores the one changed field in a comparison copy to assert that all other validated configuration fields are identical.

No model, provider, comparator, MAC, PHY, NWK or timer source is changed. All 99 original model artifacts and 58 previous isolated MATLAB helper/class files remain byte-identical. The 29 prior source transforms remain unchanged. The exact recovered 16-test policy class is reused with bounded captured queue-order probes; those additions require owner MATLAB execution. Their controlled MAC callbacks are not new PHY or campus evidence. O remains an isolated policy experiment, with no promotion or long-run 15% parity claim.
