# Tranche 20: full-campus seed variation

Copy your accepted T19 installation to a short folder such as `C:\csr20`.
Extract every file in `t20up.zip` over that copy, accepting replacements.
Use the same MATLAB R2025a installation that produced the accepted T19 return
(version 25.1.0.2943329). Exact runtime identity is checked so a release change
does not confound this seed comparison.

From the copied installation, run:

```matlab
clear functions
report = run_tranche20_validation;
```

This runs all 716 portable tests and two fresh 6,000-second campus cases:

| Case | Seed | Policy | Execution |
| --- | ---: | --- | --- |
| Accepted T19 `a128` | 128 | `actual-tx` | Reused from the bundled verified owner archive |
| `s129` | 129 | `actual-tx` | Fresh MATLAB run |
| `s130` | 130 | `actual-tx` | Fresh MATLAB run |

The simulator, original traffic, PHY/ECC and continuous timing are unchanged.
The experimental T19 policy is not part of this comparison. All accepted T19
source files remain unchanged; this update adds the experiment runner and
review tools. Matching native references for the additional seeds are bundled.

Budget several hours. Your latest default campus simulation took about 58
minutes; the additional seeds can take different amounts of time. Each case
prints its start and completion, with no extra simulation callbacks for
progress reporting. The full test suite also runs before the default workflow.

Upload **`results/t20/t20.zip`** after completion. The return review will compare
individual flows and totals for all three seeds, show their means and ranges,
and evaluate the descriptive ±5% target. Three seeds are an initial variation
screen, not a statistical-equivalence result. Matching seed numbers do not
imply matching packet-level random draws across simulators.

You can run the stages separately using the same output folder:

```matlab
report = run_tranche20_validation([],struct('Phase','tests'));
report = run_tranche20_validation([],struct('Phase','s129'));
report = run_tranche20_validation([],struct('Phase','s130'));
report = run_tranche20_validation([],struct('Phase','finalize'));
```

Completed stages are reused only after all source, reference, candidate,
runtime and saved-output identities verify. A partially executed simulation
is never resumed. Preserve failed/interrupted results for review; the detailed
recovery procedure is in `docs/tranche-20-runner.md`.

Preparation results are recorded under `evidence/tranche-20-preparation`.
MATLAB execution of this update remains pending on your machine.
