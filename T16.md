# Tranche 16

This milestone compares continuous and optional nanosecond receive timing in twelve real-network runs. It reuses two workloads at three seeds, retains the existing traffic and native references, and keeps the default timing behavior as the control.

Use a short installation path such as `C:\csr16`. Keep the working Tranche 15 installation available while this candidate is being evaluated.

After installing the complete package, or applying the update to a copy of the reviewed Tranche 15 installation, open MATLAB in the installation root and run:

```matlab
clear functions
report = run_tranche16_validation;
```

The script runs MATLAB preflight/regression tests, prints progress for each of the twelve simulations and packages the result as `t16.zip`. Return that ZIP for review. Output paths use `results/t16` and short case keys such as `a128` and `c128`.

Prior runs suggest roughly half an hour overall on the owner's laptop; export cost, competing workloads and newly exercised timing paths may change this. The estimate is not a timeout. The script records incomplete evidence if an error occurs.

This is a candidate awaiting MATLAB execution. Earlier acceptance runners bind their original source hashes; run those from the preserved installation they validated. Tranche 16 itself runs the retained functional tests against the current candidate.

See `docs/tranche-16-spec.md` for the policy, measured outcomes, scope and next release gate.
